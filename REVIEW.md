## Looked at and Decided Was NOT a Defect

1. **`load_dotenv()` without explicit override:** Defaults to `override=False`, which correctly lets real environment variables from the OS or grader take precedence over `.env` values — standard twelve-factor behaviour.
2. **`IST` timezone as `timezone(timedelta(hours=5, minutes=30))`:** This is the exact, correct UTC+05:30 offset for Indian Standard Time.
3. **Synchronous `def` handlers with PyMongo:** FastAPI runs synchronous path functions in an external threadpool via `anyio.to_thread.run_sync`, so they do not block the event loop.
